# 🎓 DataCamp Learning Journey

## 🌍 Overview

This repository documents my **DataCamp learning journey**, made possible through a **scholarship opportunity** offered by  
**[Data Engineering Pilipinas](https://dataengineering.ph/)** in partnership with **[DataCamp Donates](https://www.datacamp.com/donates)**.  

Through this program, I gained free access to DataCamp’s premium learning tracks, allowing me to enhance my skills in **data analysis**, **data visualization**, and **business intelligence** using various tools and technologies.

📖 More information about the scholarship program can be found here:  
👉 [https://dataengineering.ph/datacamp-donates.html](https://dataengineering.ph/datacamp-donates.html)

---

## 📁 Repository Contents

This repository contains:

- 🧠 **Courses and Tracks** I completed on DataCamp  
- 🏅 **Certificates of Accomplishment** for each finished course or career track  
- 💡 **My Own Solutions** to the coding exercises, challenges, and projects

Each folder represents a specific **career track** or **course**, containing:
- A `README.md` describing the course and skills learned  
- Screenshots or images of the **certificate** and **badge**  
- My submitted **solutions** or **notebooks** (where applicable)
