## 📘 About the Track

The **Data Analyst in Power BI** career track equips learners with the technical and analytical skills needed to transform data into actionable insights.  
Throughout the track, I learned how to:

- 📈 Build **interactive dashboards** and **reports** in Power BI  
- 🧮 Perform **data modeling** and **DAX calculations**  
- 🗂️ Clean and transform data using **Power Query (M language)**  
- 🔗 Connect and manage **data sources** efficiently  
- 📊 Apply **data visualization best practices** to tell compelling stories  
- 📢 Share and collaborate on reports within Power BI Service
